A release here waits for a person: Christopher decides. No agent works this
stage. The release carries the question and what stopped it, written by
whoever sent it here; if it does not, ask them before deciding.

A release leaves once the answer is on it, as a note. The stage has no
outcomes; the person answering moves it (`yardr review -g decisions`, or
`yardr bead advance <id> --to <stage>`):

- to `build`, when the release is to be built again (the tag and the release
  deleted first, where the run made them);
- to `sign`, when the checksums are to be signed again without rebuilding;
- to `verify`, when the signature is to be checked again;
- to `publish`, when the sync bead is to be filed again;
- to `backlog`, when the answer changes what the release is and the
  yardmaster must reshape it.
